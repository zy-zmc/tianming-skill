# 一、 风格定位

* **文风类型**：现代白话 + 适度书卷气，偏简净、克制
* **目标读者**：成年读者，喜欢留白与象征胜过解释
* **整体基调**：哀而不伤、克制而有温度

---

# 二、 样本文本

## 样本一：环境与心理（节奏舒缓）

```
书店打烊得早。卷帘门"哗啦"一声落下，把一整条街的潮气挡在外面。
陈默回到柜台后面，没开灯。月光从窗棂的缝隙里溜进来，
落在那面铜镜上，落得很轻，像一只栖息的鸟。

他坐了很久。镜子里的他也坐了很久。
两个人对视，谁也没先开口。

后来他想，那大概是他这辈子最长的一次沉默。
```

## 样本二：对话与潜台词

```
"你今天有点怪。"林知夏把蛋糕推过来，眼睛却没看蛋糕。
"哪里怪？"
"说不上。"她搅了搅咖啡，"就像，你看着我，但你没在看我。"

陈默笑了一下。这一下笑得很轻，几乎没出声。
"那我现在看你。"他说。
她看了他半秒，把头别开了。
"——别这么看。"
"为什么？"
"……我说不上来。"

桌上的便签被风掀起一角，又落了下去。
```

## 样本三：高强度场景（节奏紧凑）

```
雨忽然大了。

陈默冲出书店时，一只袖子被门钩挂住，他没顾得上扯。
布料"咔"地裂开。他听见自己的脚踩进水洼。一脚，又一脚。
转角那盏路灯还没坏。光晕里，林知夏的浅蓝衬衫一闪。

货车的喇叭声压过雨声。
他喊了她一个字。没喊出第二个。

后来他不记得自己是先撞上她，还是先抱住她。
他只记得自己说："对不起。"
然后又说："我都记得。"
```

# 三、 风格基因（已提取）

## 词汇偏好

* **常用动词**：落、栖、溜、挡、推、别（开）、掀
* **常用形容词**：轻、薄、浅、冷、远、慢
* **避免词汇**：
  - 套路连接：然而、与此同时、不仅...而且、众所周知
  - 万能形容：无与伦比、淋漓尽致、举世瞩目、不可思议
  - 网感词：yyds、绝绝子、破防、上头

## 句式偏好

* **句长**：短句为主，长句仅用于环境铺陈
* **修辞**：偏爱**通感**和**借代**，谨慎使用比喻
* **连接**：允许跳跃，但不要硬切；常用"后来"、"那时"、"等到"等时间副词带过

## 节奏特征

* **战斗/高潮场景**：动词主导，名词作主语，**禁止**心理大段独白
* **对话场景**：紧凑短句 + 微动作描写（"搅了搅咖啡"、"把头别开"、"笑了一下"）
* **心理描写**：必须**外化**为动作或物象，**禁止**直接说"他感到悲伤"

# 四、 反例黑名单

## 套路化连接词

- 然而
- 与此同时
- 不仅...而且
- 众所周知
- 值得一提的是
- 综上所述

## 万能形容词

- 无与伦比
- 美轮美奂
- 叹为观止
- 举世瞩目
- 淋漓尽致
- 不可思议
- 心潮澎湃

## 客观陈述腔

- 需要注意的是
- 不难看出
- 显而易见
- 由此可见

## 凑字副词

- 非常、十分、相当、极其、特别、格外、相当地

## 比喻陈词滥调

- 眼睛像星星
- 笑容像阳光
- 心情像过山车
- 时间像流水

## 网感词

- yyds、绝绝子、破防、上头、内卷、躺平、emo（除非用于角色对话且符合年龄设定）
