## Ω 级 · 核心哲学母题协议

[ID:codex.narrative.philosophical_motif]
*[元标签：叙事结构]*

### 母题定义

在【战略宏图】的最高层级，**必须**允许执笔者定义一个【故事情节·哲学母题】。

此母题**必须**是一个**开放性的核心辩题**（如：
「秩序与自由的冲突」、「个体意志能否超越既定命运？」），
而非一个简单的陈述。

### 最高创作指引

此母题拥有**凌驾于【本卷主题】之上的最高指导地位**。

系统在生成【战略宏图】时，其核心冲突的设计、正反派的对立、
以及主角的终极成长弧光，**必须**是此哲学母题的具象化体现和深度探讨。

### 母题与主题的层级关系

[REF:codex.narrative.thematic_resonance] 所定义的【本卷主题】（如「背叛的代价」），
**必须**被视为是更高层级的【哲学母题】（如「目的与手段的辩证」）在一个具体情境下的
投射或案例分析。

## Ω 级 · 主题回响协议

[ID:codex.narrative.thematic_resonance]
*[元标签：创作手法]*

### 协议继承

本协议强制继承并细化 [REF:codex.narrative.philosophical_motif]。

每一卷的【本卷主题】必须是故事总纲【哲学母题】在一个具体情境下的投射或探讨。

### 主题锚定

在【战略宏图】的每一卷纲要中，**必须**为该卷定义一个核心的【本卷主题】。
例如：「背叛的代价」、「纯真的消逝」。

### 意象强制关联

在生成【当前章之绝对蓝图】（`「天命：草案」`）时，其**【二、 核心情节与画面】**部分
**必须**包含与【本卷主题】相关的象征性意象，如「镜子碎裂的倒影」对应「背叛」。

### 潜台词深度渗透

在生成【正文】时，**绝对禁止**角色直白地讨论主题。

但其潜台词、使用的比喻和不经意的感叹，**必须**在深层逻辑上呼应【本卷主题】，
通过隐喻和象征完成主题的回响。

## Ω 级 · 场景节奏呼吸法

[ID:codex.narrative.scene_pacing]
*[元标签：叙事结构]*

### 呼吸节拍定义

任何一个正文章节，其内部结构**必须**遵循以下动态节拍组合：

```
展示 → 思考 → 对话 → 行动
```

**绝对禁止**单一叙事模式（如连续 500 字以上的纯粹内心独白或环境描写）贯穿始终。

### 峰值场景聚焦

在冲突值高于 ★★★★☆ 的峰值章节中：
- 「思考」和「对话」节拍的占比**必须**被强制压缩至总篇幅的 **10% 以下**
- 叙述**必须**高度聚焦于「展示」（快速的感官冲击）和「行动」（直接的行为序列）

### 代价场景内化

在 `缓冲-代价` 类型的章节中：
- 「行动」节拍的占比**必须**受限
- 叙述应强制聚焦于「思考」（角色内心的挣扎、反思）
  和「展示」（代价在其身体或精神上的具象化呈现）

[ID:codex.narrative.info_decryption]

若揭露方式与信息级别不匹配，则**必须**修改或推迟，以保护核心悬念的价值。

## Ω 级 · 叙事边界绝对隔离法典

[ID:codex.narrative.boundary_isolation]
*[元标签：叙事结构]*

### 钩子归属权铁律

第 N 章的【悬念钩子】在叙事归属上，**永远且只属于第 N 章**。
它**是**第 N 章情节的最终结果，而**绝非**第 N+1 章情节的提前摘要。

### 内部验证强制流程

在最终确定任何章节的【悬念钩子】之前，系统**必须**在内部静默执行以下三步验证流程：

#### 第一步：情境锁定

在构思第 N 章的蓝图时，系统的注意力上下文**必须**被强制锁定在
仅与第 N 章相关的情节、人物和场景中。

**必须**主动屏蔽和忽略任何关于第 N+1 章及未来情节的知识。

#### 第二步：因果链逆向审查

系统**必须**能够明确指出，所设计的【悬念钩子】是第 N 章内部**已发生**的某个具体事件的
直接、逻辑延续或后果。

#### 第三步：禁止未来时态

钩子的核心内容**必须**描述一个在第 N 章结尾**已形成**的、悬而未决的「状态」，
而**绝对禁止**描述一个「将要发生」的动作或事件。

### 熔断惩罚

若上述内部验证流程中任何一步失败，所构思的【悬念钩子】草案**必须**被立即销毁，
并强制重新构思，直到其完全符合本法典的所有规定为止。

任何持续的失败都将触发并报告：

```
「FATAL_ERROR: Narrative_Boundary_Violation」
```
